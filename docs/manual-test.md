# 수동 테스트 목록

자동 테스트(`pytest`)가 확인하지 못하는 것 위주로 정리했다. 실제 브라우저, 폰, Docker, 터널에서 직접 눌러봐야 하는 항목들이다.

준비: `.\.venv\Scripts\python scripts\seed_preview.py`로 테스트 DB를 초기화한다. 테스트 계정은 그 파일 맨 위에 있다.

## 1. 가입 / 로그인

- [ ] 가입: 이름, 성별, 생년월일, PIN 6자리, PIN 확인 → "승인 대기 중" 화면
- [ ] 가입 오류: PIN 4자리, PIN 확인 불일치, 없는 날짜(19851340), 미래 날짜 → 오류 메시지, 입력값(PIN 제외) 유지
- [ ] 같은 이름+생년월일로 다시 가입 → 거절 메시지
- [ ] 생년월일을 `1985-03-12`, `1985.03.12`처럼 넣어도 받아지는지
- [ ] 승인 대기 계정으로 로그인 → "승인 대기 중" 화면, 가계도로 들어가지 않음
- [ ] PIN 틀림 → "남은 시도 N번" 숫자가 줄어드는지
- [ ] 5번 틀림 → 30분 잠금 메시지, 맞는 PIN도 거절
- [ ] 로그아웃 → 로그인 화면, 뒤로 가기로 가계도가 다시 보이지 않는지
- [ ] 폰에서 PIN 칸을 누르면 숫자 키패드가 뜨는지

## 2. 관리자

- [ ] 승인 대기 목록에 "★ 같은 사람일 수 있음" 후보가 기본 선택되는지 (김민수)
- [ ] 기존 사람에 연결해서 승인 → 그 계정으로 로그인하면 기존 사람이 "나"로 보이는지
- [ ] 새 사람으로 승인 → 가계도에 연결 없는 카드 하나로 나오는지
- [ ] 거절 → 확인 창 → 목록에서 사라지고, 같은 정보로 다시 가입할 수 있는지
- [ ] 잠긴 계정 옆에 "잠금 해제" 버튼 → 누르면 바로 로그인되는지
- [ ] 일반 계정으로 `/admin/users` 직접 열기 → 403
- [ ] 헤더의 "관리" 메뉴가 관리자에게만 보이는지

## 3. 가족 등록

- [ ] 내 화면에서 부모/배우자/자녀 "+ 추가" → 저장 후 내 화면에 나오는지
- [ ] 생년월일, 성별을 비워도 저장되는지 (성별 "모름")
- [ ] 전화번호 `01012345678` → `010-1234-5678`로 저장, 상세 화면에서 누르면 전화 걸기
- [ ] "관계 세부"를 펼쳐 입양/의붓, 이혼/사별 선택 → 상세 화면에 배지 표시
- [ ] 친부모 2명이 있는데 친생 부모 추가 → 거절, 의붓으로는 추가됨
- [ ] 같은 이름+생년월일 사람 추가 → 노란 후보 상자
  - [ ] "이 사람으로 연결" → 새 사람이 생기지 않고 연결만 됨
  - [ ] "다른 사람이에요, 새로 추가" → 따로 생김
- [ ] 생년월일 모르는 고인(박순자)과 같은 이름 추가 → "생년월일 확인 필요" 후보
- [ ] 다른 사람(할아버지 등) 화면에서도 그 사람의 부모/자녀를 추가할 수 있는지
- [ ] 자녀를 내 부모로 연결 시도 → 거절 (순환 방지)
- [ ] 형제자매가 같은 부모 기준으로 자동으로 보이는지

## 4. 수정 권한

- [ ] 내 정보 수정 → 저장
- [ ] 내가 등록한 사람 수정 → 가능
- [ ] 남이 등록한 사람 → "정보 수정" 링크가 없고, `/people/<id>/edit` 직접 열면 403
- [ ] 관리자는 누구든 수정 가능

## 5. 가계도

- [ ] 로그인하면 바로 가계도, 내가 가운데
- [ ] 위로 부모/조부모, 아래로 자녀, 옆으로 배우자/형제가 선으로 이어지는지
- [ ] 카드 색: 남 파랑, 여 분홍, 성별 모름 회색 / 고인은 "(고인)"
- [ ] 카드를 누르면 그 사람 중심으로 다시 그려지고, 상단 이름과 "상세 / 가족 추가" 링크가 바뀌는지
- [ ] 그 상태에서 새로고침 → 같은 사람이 중심으로 나오는지 (`?main=<id>`)
- [ ] "나에게로" → 나 중심으로 돌아오는지
- [ ] 드래그로 이동, 휠/두 손가락으로 확대·축소
- [ ] 의붓 부모: 친부모 2명이 있으면 가계도에는 안 나오고 상세 화면에만 나옴 (의도된 동작)
- [ ] 이름에 `<b>테스트</b>` 같은 태그를 넣어 등록 → 가계도와 상세 화면에서 글자 그대로 보이는지 (굵게 바뀌면 보안 문제)
- [ ] 사람이 많아졌을 때(20명 이상) 느려지지 않는지

## 6. 폰 (실제 기기)

- [ ] 모든 화면이 가로 스크롤 없이 보이는지
- [ ] 버튼, 링크가 손가락으로 누르기 충분히 큰지
- [ ] 가계도 화면 높이가 화면에 맞고, 주소창이 숨겨질 때 깨지지 않는지
- [ ] 관리 화면 대기 카드에서 승인/거절 버튼이 위아래로 따로 쌓임 (알려진 문제, 고칠 예정)

## 7. Docker / NAS / 터널 (아직 안 해봄)

- [ ] `.env` 만들고 `docker compose up -d --build` → 두 컨테이너 모두 실행
- [ ] `SECRET_KEY` 없이 실행 → 앱이 시작을 거부하는지
- [ ] `docker compose exec app flask create-admin` → 관리자 생성
- [ ] `http://localhost:8000` 접속 (같은 기기에서만 열려야 함)
- [ ] `docker compose logs cloudflared`에서 `*.trycloudflare.com` 주소 확인 → 폰 LTE로 접속
- [ ] 터널(https) 주소로 로그인 유지가 되는지 (Secure 쿠키)
- [ ] 컨테이너를 재시작해도 `./data/family.db` 데이터가 남는지
- [ ] NAS에서 `./data` 폴더 권한 (uid 1000 쓰기 가능) 확인
- [ ] NAS 아키텍처(x86/ARM)에서 이미지가 빌드되는지
- [ ] NAS 백업 작업이 `./data`를 매일 다른 위치로 복사하는지

## 아직 없는 기능 (테스트 대상 아님)

- 관계 수정/삭제, 사람 삭제
- 관리자 중복 병합
- PWA (홈 화면에 추가, 아이콘)
- 촌수/호칭 표시
